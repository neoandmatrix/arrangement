# Bandobast

A phone agent that arranges family functions (griha pravesh, pooja, small events) in another city: it calls local organizers in their language, compares quotes, and follows up so nobody backs out at the last minute.

Built for the Great Indian AI Internship Challenge on Gnani **Prisma v3.0** (speech-to-text) and **Timbre v3.0** (text-to-speech).
